## What it does

`main.ts` writes one sentence — the single line that could have replaced an
entire pointless meeting — to `/output/entry.txt`:

> Sixty minutes, no decision, no owner, no deadline: this meeting ended
> before it started — we're just still sitting in it.

## Run

```sh
node main.ts
```

Requires Node 22.18 or later. The program uses only the Node standard
library, writes deterministically, and needs no network access.
